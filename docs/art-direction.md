# Deja Vu art direction

Use these visual keywords as the shared direction for generated game artwork:

- Neon rim lighting
- Cyan and magenta glow
- Chromatic aberration
- Glitch effects
- Holographic display
- Synthwave color palette
- Futuristic megacity
- Anime cel shading
- High-contrast lighting
- Volumetric neon fog
- Digital noise
- Electric atmosphere
- Hyper-saturated colors
- Night cityscape
- Cybernetic implants

Not every asset needs every treatment. Functional interface assets should remain immediately
recognizable first, using the shared lighting and palette as restrained accents.

## Dice palette

- D4: green
- D6: blue
- D8: red/coral
- D10: hot pink
- D12: purple
- D20: amber/gold

Dice use traditional tabletop geometry with exactly one valid numeral per face. They should read
as ordinary resin dice with neon rim lighting, never as machines, alien artifacts, or magical items.
