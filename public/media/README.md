# Built-in media

This directory contains version-controlled artwork shipped with the game.

- `characters/sheets`: original five-expression character sheets used by authors.
- `characters/portraits`: runtime-ready expression portraits used by characters and dialogue.
- `minigames/dice`: dice textures and dice-related interface artwork.
- `minigames/lohi`: LoHi card and library artwork.
- `minigames/netrunners`: NetRunners player avatar artwork.
- `story`: maps and other built-in story artwork.
- `story/sources`: author references and source concepts that are not shown in the image library.
- `ui`: shared interface artwork.

User-uploaded files remain under `public/uploads`, while music and sound effects remain under
`public/audio`. Generated application bundles remain under `public/assets`.
